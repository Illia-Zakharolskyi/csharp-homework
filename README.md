# csharp-homeworks

![Language](https://img.shields.io/badge/C%23-10.0-green)

A collection of C# console applications and exercises focused on learning C# fundamentals and Object-Oriented Programming (OOP).

---

## 🛠 Tech Stack

- **Language:** C#
- **Tools:** Visual Studio

---

## 🚀 How to Run

1. Clone the repository:
   ```bash
   git clone [https://github.com/Illia-Zakharolskyi/csharp-homeworks.git](https://github.com/Illia-Zakharolskyi/csharp-homeworks.git)

2. Open the desired project folder (for example, csharp-homeworks/Homework/2025/xx_07_2025/Homework_30_07_2025).

3. Open the .csproj file or open the project folder in your IDE (Visual Studio / VS Code).

4. Run the project using your IDE (e.g., press F5 or use the Integrated Terminal).
